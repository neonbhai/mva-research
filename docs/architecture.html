Layer 3 is the interesting one

privacy is cross-cutting, so any stage can call it, while it stays structurally unable to import upward.

VariantRecord

  • A build-anchored coordinate.
  • A genotype with its analytical evidence.
  • Lists of transcript consequences and population frequencies.

Immutable and additive: annotation returns a new record, so ingested and annotated are separately hashable artifacts.

EvidenceItem

One structured, attributable, falsifiable claim, with mandatory limitations.

  • Content-derived IDs mean the same conclusion drawn twice is one piece of evidence, so the ID is stable across runs.
  • The record is not byte-identical across runs under a real clock: timestamp is excluded from the ID but is still written to evidence_items.parquet.

Storage ADR 0002

  • DuckDB for querying.
  • Parquet for large typed artifacts.
  • No server.

The graph structure is stored relationally in a graph_edges subject/predicate/object table.

variant → gene → mechanism → drug

subjectpredicateobject

The domain is a graph, but the queries are shallow and the data is small. Keeping edges relational avoids a second system to secure and delete, and leaves the export path open.

Repeat two runs, compare the hashes

How it is checked

just demo-determinism

Runs the demo twice and compares artifact hashes, skipping provenance.json and the DuckDB container by filename.

Nothing has ever run it against a non-synthetic config, and pointed at one it would report a failure on the eleven time-bearing artifacts.

Five mechanisms

  1. All timestamps come from an injected Clock; a lint forbids datetime.now().
  2. Evidence and pair IDs are content-derived.
  3. Every sort key is total: score, then genomic position.
  4. Parquet writes are sorted by primary key with pinned compression and row-group size, and the writer embeds no timestamp of its own, though evidence_items carries the evidence timestamp as data.
  5. Canonical JSON for every hash.

Workflow ADR 0001

Snakemake expresses the DAG, but the rules are thin: they shell out to mva subcommands so the logic stays in tested Python.

The same DAG runs without Snakemake via mva run all, so the workflow engine is a convenience rather than a dependency.

The list

TD-02No known-answer validation. The synthetic case proves the machinery, not the calibration. No real-world sensitivity claim is supportable yet.
TD-03No structural or copy-number variant calling. In a chromosomal-instability disorder that is a material gap, not a rounding error.
TD-07Proband-only. No segregation, no de-novo detection, no trio phasing, so phase stays UNKNOWN for every pair and the inheritance component is capped.
TD-04Phenotype matching is flat term overlap. No ontology-graph propagation, so true matches are under-scored.
TD-06Network denial is a tripwire, not a boundary. C extensions and subprocesses bypass the Python guard.
TD-21Determinism is verified under a fixed clock only. Eleven artifacts are time-bearing under a real clock.
TD-09No human domain-expert review. Adversarial model review is a filter, not a substitute, and treating model fluency as evidence quality is the exact failure this project exists to resist.
no idEvery scoring weight is heuristic, calibrated against no labelled dataset. No composite score is a probability.
